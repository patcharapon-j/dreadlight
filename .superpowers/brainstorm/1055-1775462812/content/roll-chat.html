Key Design Decisions
  • 6s glow — success dice have box-shadow and brighter color
  • 1s are color-coded — base 1s blue (Mind), dread 1s purple (Soul), gear 1s red (break)
  • Locked dice (push) get a gold border ring
  • Consequence callouts — colored boxes clearly showing Mind/Soul/Gear costs
  • Card border color changes per result type: gold (clean), purple (tainted), muted (fail)
  • Push always available on initial roll, removed after pushing
  • Pool preview in dialog shows exact die split before rolling
