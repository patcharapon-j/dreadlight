Dread as Independent Track — Design Overview

Hunger-style standalone mechanic, decoupled from Soul loss

Core Concept

Dread becomes a standalone 0–5 track with no mechanical derivation from Soul. The GM defines what "Dread" represents per campaign — supernatural corruption, paranoia, moral decay, creeping desperation — and assigns gains/losses based on narrative triggers.

What Changes

❌ Removed

  • Auto-derivation from Soul loss
  • Soul Lost → Dread lookup table
  • Dread Recovery section ("follows Soul")
  • dread.override toggle (no longer needed)
  • CONFIG.DREADLIGHT.dreadTable

✅ Added / Changed

  • Dread is a simple value field (0–5)
  • GM increases Dread via narrative triggers
  • Players decrease Dread via safe scenes & actions
  • Dread track is directly editable on the sheet
  • New rules text: gaining/losing Dread guidance

What Stays the Same

  • Max Dread: 5
  • Dread dice replace base dice in pools
  • Dread 6s → tainted/dire outcomes
  • Pushing dread 1s → Soul loss
  • Roll outcome categories (clean/tainted/dire/failure)
  • GM Dread Pool (fully separate resource)
  • Conditions system unchanged
  • All other dice mechanics unchanged
