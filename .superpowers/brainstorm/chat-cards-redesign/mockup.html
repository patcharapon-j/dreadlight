A · Dossier / Case File. Each card reads like a sheet pulled from a classified field-report folder. Typewriter labels, redaction bars, evidence-tag dice, and a large angled rubber-stamp seals the verdict. Critical hits earn a small bottom-corner stamp ("CRITICAL · TARGET COMPROMISED"). Push becomes a footer action so the stamp can dominate.

C · Field Transmission / CRT. Compressed, terminal-like. Each card opens with a timestamp + signal indicator, the action is rendered as a shell prompt, dice are tight monospace pip-rows, the outcome is shown as signal-bars + verdict word. Dire failure / lethal injuries glitch the text. Maximum information density.
